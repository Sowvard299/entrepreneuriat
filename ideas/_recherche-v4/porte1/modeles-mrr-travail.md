# Modèles à revenus publiés (TrustMRR, Starter Story) : fichier de travail

- Mission : relever 10 petites entreprises rentables à l'étranger (MRR publié), puis l'état du marché FR. Exclusions du coordinateur respectées ; aucune annonce Acquire.com.
- Date : 2026-11-02
- Recherches web utilisées : 9 / 12 (le reste en WebFetch et API Sirene)
- Preuves : 10 modèles (M1 à M10) + 9 preuves FR (F1 à F9) + 1 contre-preuve (C1)
- Domaines distincts : trustmrr.com, starterstory.com, bulletpointpodcast.pages.dev, parseur.com, formspree.io, recherche-entreprises.api.gouv.fr, franceangels.org / lejournaldesentreprises.com, pabau.com, lonasante.com, ellty.com, hackceleration.com, resufit.com, lafabriquedunet.fr
- Réserve : trustmrr.com fournit 10 preuves sur 20 (50 %), au-delà des 40 % : la mission portait sur TrustMRR. Les preuves FR viennent d'autres domaines.
- Nature du MRR TrustMRR : revenu lu via le processeur de paiement (Stripe), annoncé par la plateforme ; chiffres en USD. Les pages ne portent pas de date de relevé : date de consultation 2026-11-02.
- Statut : partiel. Manque : prix FR vérifiés sur les sites éditeurs (Doctolib, Dealroom, KontoCSV bloqué/parqué), nombre de clients FR chiffré pour la plupart, concurrents FR de M4, M8, M9.

## Partie A : preuves étrangères (argent encaissé)

### M1 : Web3Forms, API de formulaire de contact
- Acteur / marché : Surjith S M (fondateur unique, bootstrap) vend une API qui envoie les formulaires de sites statiques vers un e-mail ; clients : développeurs et agences web.
- Type : argent dépensé
- Source : https://trustmrr.com/startup/web3forms (date : consulté 2026-11-02, ouvert)
- Citation : « Contact Form API for Modern Websites. »
- Chiffres : MRR 43 720 $ ; 3 176 abonnements actifs ; 353 786 $ cumulés ; lancé décembre 2020 ; gratuit jusqu'à 250 envois/mois
- Ce que ça dit pour nous : un produit minuscule peut encaisser 44 k$/mois, mais c'est un produit développeur, en anglais, sans angle français.

### M2 : Maildroppa, e-mailing pour solopreneurs
- Acteur / marché : Marcus Biel (Allemagne, 0 salarié, freelances Upwork) vend une plateforme d'e-mailing à des solopreneurs.
- Type : argent dépensé
- Source : https://www.starterstory.com/stories/maildroppa (date : 2024-05-09, ouvert)
- Citation : « I Built An Email Marketing Tool For Solopreneurs That Makes $20K/Mo »
- Chiffres : ~20 000 $ MRR ; ~500 clients payants ; revenu moyen ~38,59 $ par client ; marge brute 75 % ; coûts ~5 000 $/mois ; lancement en février 2021 ; ~2 000 $ de Google Ads au lancement
- Ce que ça dit pour nous : la preuve la plus proche de notre profil marketing (acquisition payante, équipe de 1 + freelances), mais le segment est saturé en France.

### M3 : Rezi, créateur de CV avec IA
- Acteur / marché : Rezi vend à des chercheurs d'emploi un créateur de CV optimisé pour les logiciels de tri.
- Type : argent dépensé
- Source : https://trustmrr.com/startup/rezi (date : consulté 2026-11-02, ouvert)
- Citation : « Build, improve, and tailor your resume with AI. »
- Chiffres : MRR 241 191 $ ; 10 016 abonnements ; 10,47 M$ cumulés ; fondé en mai 2015 ; Pro 29 $/mois ; à vie 149 $
- Ce que ça dit pour nous : très gros, mais 11 ans d'ancienneté et un marché FR plein : pas un modèle « jeune et peu capitalisé ».

### M4 : 1Lookup, API de validation téléphone / e-mail / IP
- Acteur / marché : Robby Frank vend à des développeurs et équipes de prospection une API de validation en temps réel (34 produits de données, crédits).
- Type : argent dépensé
- Source : https://trustmrr.com/startup/1lookup (date : consulté 2026-11-02, ouvert)
- Citation : « Real-time phone, email, and IP validation API »
- Chiffres : MRR 258 371 $ ; 749 abonnements ; 5,69 M$ cumulés ; fondé janvier 2022 ; prix à l'usage (non détaillé)
- Ce que ça dit pour nous : très fort revenu par client (~345 $/mois), mais produit technique : besoin d'un associé tech.

### M5 : Angel Match, base de 124 000 business angels et VC
- Acteur / marché : abonnement donnant accès à une base d'investisseurs, vendu à des fondateurs qui lèvent un tour d'amorçage.
- Type : argent dépensé
- Source : https://trustmrr.com/startup/angel-match (date : consulté 2026-11-02, ouvert)
- Citation : « database of 124,000 angels and VCs to raise your seed round. »
- Chiffres : MRR 27 079 $ ; 325 abonnements actifs (soit ~83 $/mois par abonnement, calcul : MRR ÷ abonnements) ; 987 394 $ cumulés ; fondé janvier 2019 ; prix non affiché
- Ce que ça dit pour nous : un produit de données pur, peu de support, avec peu de clients.

### M6 : Calendesk, réservation + paiements pour thérapeutes et indépendants
- Acteur / marché : société polonaise bootstrap vend une solution de rendez-vous, paiements, forfaits et marque blanche à des psychologues, thérapeutes et prestataires de services.
- Type : argent dépensé
- Source : https://trustmrr.com/startup/calendesk (date : consulté 2026-11-02, ouvert)
- Citation : « helps service professionals manage bookings and payments »
- Chiffres : MRR 20 918 $ ; 371 abonnements ; 1,16 M$ cumulés ; fondé mai 2020 ; Standard 79 $/mois (annuel) ou 97 $ ; Pro 117 $/mois (annuel) ou 147 $
- Ce que ça dit pour nous : des indépendants paient 79 à 147 $/mois un outil qui ajoute le paiement et les forfaits à l'agenda.

### M7 : Bank Statement Converter, PDF de relevés bancaires vers Excel
- Acteur / marché : Angus Chang, seul, vend à des cabinets financiers, comptables et juridiques la conversion de relevés bancaires PDF en Excel / CSV.
- Type : argent dépensé (déclaratif, non vérifié Stripe)
- Source : https://bulletpointpodcast.pages.dev/starterstory/i-make-40k-month-with-this-one-website (date inconnue ; extrait de recherche, résumé de vidéo Starter Story) ; site : https://bankstatementconverter.com (ouvert 2026-11-02, prix non affichés)
- Citation : « he launched it in 2021 and today it makes $40k a month and he runs it entirely by himself. »
- Chiffres : ~40 000 $/mois (déclaré) ; ~62 500 visiteurs/mois (résumé tiers) ; offres gratuites limitées par pages/24 h ; prix non trouvé
- Ce que ça dit pour nous : confiance faible (résumé tiers, pas d'audit), mais le modèle « outil unique, trafic SEO, abonnement » est le plus simple à copier.

### M8 : Stack Influence, marketing de micro-créateurs pour e-commerce
- Acteur / marché : plateforme qui automatise les collaborations avec de micro-créateurs, vendue à des marques e-commerce.
- Type : argent dépensé
- Source : https://trustmrr.com/startup/stack-influence (date : consulté 2026-11-02, ouvert)
- Citation : « Automate authentic creator collaborations at scale without negotiating fees. »
- Chiffres : MRR 26 591 $ ; 54 abonnements actifs (soit ~492 $/mois chacun) ; 29,1 M$ cumulés ; fondé janvier 2020 ; plans 499 / 1 799 / 6 000 $ par mois
- Ce que ça dit pour nous : 54 clients suffisent à 26 k$ de MRR : cible B2B facile à nommer (marques e-commerce), mais plateforme à deux faces (créateurs et marques).

### M9 : Heron Copier, journal de trading et copie d'ordres
- Acteur / marché : outil par abonnement pour traders particuliers (journal de trades + copie multi-plateformes).
- Type : argent dépensé
- Source : https://trustmrr.com/startup/heron-copier (date : consulté 2026-11-02, ouvert)
- Citation : « 7-day free trial, $19/month, or $179/year. »
- Chiffres : MRR 7 779 $ ; 410 abonnements ; 503 295 $ cumulés ; fondé juin 2023 ; 19 $/mois ou 179 $/an
- Ce que ça dit pour nous : un produit B2C à 19 $/mois atteint 410 clients en ~2,5 ans ; le copy-trading peut relever de la réglementation financière (non vérifié), à examiner avant tout.

### M10 : Postiz, programmation de réseaux sociaux
- Acteur / marché : outil de planification de publications (open source, agents IA), vendu à des créateurs et équipes marketing.
- Type : argent dépensé
- Source : https://trustmrr.com/startup/postiz (date : consulté 2026-11-02, ouvert)
- Citation : « agentic social media scheduler tool »
- Chiffres : MRR 352 049 $ ; 10 324 abonnements ; 1,69 M$ cumulés ; fondé juillet 2024 ; dès 29 $/mois
- Ce que ça dit pour nous : le plus rapide de la liste (16 mois), mais un marché mondial saturé (Hootsuite, Buffer...) ; l'avantage tient au code ouvert, pas à une niche.

## Partie B : état du marché français

### F1 : M5, prix des bases d'investisseurs (concurrents FR et mondiaux)
- Acteur / marché : Dealroom, Crunchbase, outils gratuits (Signal NFX, Foundersuite).
- Type : tendance (prix issus de comparateurs, contradictoires)
- Source : extrait de recherche (non ouvert) : https://www.ellty.com/blog/what-is-dealroom (date inconnue)
- Citation : « Dealroom : un comparatif indique 395 €/mois et plus » (reformulation du résumé de recherche, pas une citation de la page)
- Chiffres : Dealroom ≥ 395 €/mois selon un comparatif, ou 200 à 1 000 $/mois selon un autre ; alternatives gratuites : Signal 18 000+ investisseurs, Foundersuite 216 000
- Ce que ça dit pour nous : le marché n'est pas vide (gratuit + payant), confiance faible.

### F2 : M5, taille de la cible FR
- Type : tendance
- Source : https://www.lejournaldesentreprises.com/article/les-investissements-des-business-angels-ont-nettement-augmente-en-2024-selon-france-angels-2118501 (date : 2025 ; extrait de recherche) ; France Angels (fédération) : https://www.franceangels.org
- Citation : « 445 start-ups aidées en 2024 » (reformulation du résumé de recherche)
- Chiffres : ~100 M€ investis en 2024 par les BA français ; 445 start-ups financées ; 12 500+ BA fédérés depuis 2001 (cumulé)
- Ce que ça dit pour nous : le volume de levées FR est de l'ordre de centaines par an, pas de milliers : pour M5 le nombre de clients FR est probablement < 3 000 [HYPOTHÈSE, à vérifier].

### F3 : M6, concurrents FR prise de rendez-vous santé / bien-être
- Type : plainte / tendance (prix déclarés par des tiers)
- Source : https://pabau.com/fr/blog/doctolib-tarif/ et https://www.lonasante.com/?p=11708 (extrait de recherche, non ouverts, date inconnue)
- Citation : « Doctolib ne publie pas ses prix » (reformulation du résumé de recherche)
- Chiffres : Doctolib ~135 à 149 € TTC/mois par praticien (témoignages, comparatif RDV360), dès 229 € avec logiciel médical ; Resalib dès 24,99 €/mois ; Liberlo dès 12 € HT/mois
- Ce que ça dit pour nous : marché occupé et segmenté par prix ; un outil à 79 $ avec paiement et forfaits se place au milieu.

### F4 : M6, nombre de professionnels FR (Sirene)
- Type : tendance (source officielle)
- Source : https://recherche-entreprises.api.gouv.fr/search?activite_principale=86.90F&etat_administratif=A&per_page=1 (date : 2026-11-02, ouvert)
- Citation : « total_results: 10000 »
- Chiffres : NAF 86.90F (activités de santé humaine non classées ailleurs, inclut psychologues et autres) : plafond API de 10 000 atteint ; dont 814 avec 1 salarié ou plus (tranche « 01 »). La part de psychologues n'est pas isolée.
- Ce que ça dit pour nous : au moins 10 000 unités, mais pas de chiffre exact par métier [HYPOTHÈSE sur la part ciblable].

### F5 : M7, concurrents FR conversion de relevés bancaires
- Type : tendance
- Source : extrait de recherche : https://parseur.com/fr/convertir/releves-bancaires/en-excel ; https://www.klippa.com/fr/blog/informations/comment-convertir-releves-bancaires-en-excel-csv/ (dates inconnues)
