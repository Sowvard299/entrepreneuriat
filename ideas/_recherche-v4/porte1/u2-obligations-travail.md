## A. Accessibilité numérique (directive UE 2019/882, décret 2023-931, applicable 28 juin 2025)

### U2-OBL-01 : texte de loi EAA en France
- Acteur / marché : sites e-commerce B2C, banque et services grand public
- Type : obligation
- Source : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000048178349 (ouverte, décret du 9 octobre 2023)
- Citation : « 5° Commerce électronique. » (art. D. 412-50, I, code de la consommation) ; microentreprises (<10 salariés, ≤2 M€) : exemption partielle art. D. 412-60
- Chiffres : date d'application 28 juin 2025 (confirmée par sk-web.fr, ouvert)
- Ce que ça dit pour nous : obligation datée et écrite en droit français ; texte de la directive EUR-Lex [NON OUVERT, page renvoyée vide].

### U2-OBL-02 : prix d'audit RGAA (sk-web)
- Acteur / marché : prestataires d'audit, vendent aux sites e-commerce
- Type : argent dépensé (prix publics affichés, non prouvés payés)
- Source : https://sk-web.fr/article/prix-audit-rgaa-2026 (ouverte, mise à jour 2026-10-15)
- Citation : « 2 000 à 5 000 € HT pour un site courant (DINUM) »
- Chiffres : vitrine 2 000-3 000 ; e-commerce 4 500-9 900 ; institutionnel 8 000-20 000+ ; offre auteur dès 2 100 € ; pack documents 790 € ; Access42 sur devis
- Ce que ça dit pour nous : 3 prix publics (2 100, 790, grilles) mais aucun client payant identifié. Confiance faible (vendeur).

### U2-OBL-03 : prix d'audit et corrections (kolonell)
- Acteur / marché : agence web
- Type : argent dépensé (prix publics)
- Source : https://kolonell.com/fr/blog/site-accessible-rgaa-entreprise-obligation-cout-2026 (ouverte)
- Citation : « Les sanctions peuvent atteindre 50 000 EUR par service non conforme »
- Chiffres : audit 2 000-6 000 € ; corrections 4 000-20 000 € ; contre-audit 800-2 500 € ; déclaration 300-1 200 € ; formation 900-2 500 € ; délai 6-12 semaines
- Ce que ça dit pour nous : le montant 50 000 € contredit sk-web (25 000 €) et la DGCCRF (7 500 €, extrait de recherche) : sanction non établie, [NON OUVERT] la source officielle (DGCCRF en 403).

### U2-OBL-04 : CA des acteurs accessibilité

## B. Formation HACCP obligatoire (code rural L233-4, décret 2011-731, arrêté 12 février 2024)

### U2-OBL-06 : texte légal
- Acteur / marché : restaurants, traiteurs, restauration commerciale
- Type : obligation
- Source : https://www.cnfce.com/faq/hygiene-alimentaire-haccp/restauration-commerciale-definition-legislation-formation (ouverte, date inconnue) ; Légifrance L233-4 [NON OUVERT, 404]
- Citation : « la présence dans les effectifs de ces établissements d'une personne pouvant justifier d'une formation spécifique »
- Chiffres : 14 heures ; sanction R237-2 contravention 5e classe (extrait de recherche, non ouvert)
- Ce que ça dit pour nous : obligation permanente, un formé par établissement, flux de renouvellement par ouvertures.

### U2-OBL-07 : nombre d'assujettis (Sirene)

- Chiffres : 56.10A restauration traditionnelle 157 165 ; 56.10C restauration rapide 175 043 ; 56.30Z débits de boissons 59 176 (inclut non employeurs)
- Type : tendance (volume)
- Ce que ça dit pour nous : > 390 000 unités, très au-dessus de 3 000 clients.

## C. Certification Qualiopi (code du travail L6316-1, en vigueur depuis 2024-01-01)

### U2-OBL-11 : texte légal
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000048600506 (ouverte)
- Citation : « Les prestataires mentionnés à l'article L. 6351-1 financés par un opérateur de compétences »
- Type : obligation
- Chiffres : certificat valable 3 ans (extrait de recherche) ; audit initial puis surveillance
- Ce que ça dit pour nous : obligation pour accéder aux fonds publics/OPCO/CPF.

### U2-OBL-12 : nombre d'assujettis
- Source : https://certiforma.fr/chiffres-formation-professionnelle/ (ouverte, relevé 2026-10-02, vendeur de service, confiance faible-moyenne ; base data.gouv)
- Citation : « more than 7 in 10 organisations are not certified » (paraphrase de la page en anglais, non copiée)
- Chiffres : 152 621 organismes déclarés ; 45 580 certifiés (29,9 %) ; 76 % mono-formateur ; DARES : ~120 000 déclarés, ~45 000 certifiés
- Type : tendance
- Ce que ça dit pour nous : ~107 000 non certifiés, dont beaucoup inactifs ; la cible active est inconnue.

### U2-OBL-13 : prix publics
- Source : https://certiforma.fr/qualiopi-cle-en-main/ (ouverte)
- Citation : « On monte le dossier avec vous. Obtenu ou remboursé. »
- Chiffres : 790 € HT autonome ; 1 790 € HT accompagné ; marché accompagnement 1 200-3 500 € ; audit initial 1 000-1 800 € ; surveillance 700-1 200 €
- Source 2 : https://culture-rh.com/audit (ouverte) : « 950€ à 1400 € HT/jour » (audit)
- Type : argent dépensé (prix publics, pas de clients identifiés)
- Ce que ça dit pour nous : 4 prix publics concordants ; marché des accompagnateurs encombré.

### U2-OBL-14 : CA des acteurs
- Source : API recherche-entreprises (ouverte)
- Chiffres : AFNOR Certification (479076002) CA 96 461 836 €, résultat 3 541 324 € en 2025 ; Bureau Veritas Certification France (399851609) CA 78 006 241 €, résultat 7 197 381 € en 2025 (certificateurs, pas accompagnateurs) ; Certiforma : pas de comptes publiés
- Type : argent dépensé
- Ce que ça dit pour nous : le CA des accompagnateurs (le segment visé) n'est pas observé.

### U2-OBL-15 : contre-preuve Qualiopi
- Type : contre-preuve
- Source : https://www.centre-inffo.fr/site-centre-inffo/qualite-plus-de-10-000-prestataires-de-formation-certifies-qualiopi (ouverte, 2020-12-02) et extrait de recherche (consultants.. « n'importe qui peut se déclarer expert Qualiopi », certiforma.fr, non ouvert)
- Citation : « Un peu plus de 10 000 prestataires sont aujourd'hui certifiés. »
- Ce que ça dit pour nous : la base certifiée a quadruplé (10 000 en 2020 vers 45 580 en 2026) : la vague d'obligation est passée, 76 % des organismes sont mono-formateurs (budget faible), 1 790 € de prix plafond. Avis négatifs précis : [NON OUVERT].
